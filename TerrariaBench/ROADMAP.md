# Implementation roadmap

1. **Foundation and real controls — implemented.** Independent directory,
   compiled tModLoader observer, immutable development fixture, Wayland capture,
   calibrated uinput control and cost-accounted OpenRouter loop. Historical
   coached wood/workbench results remain in [LIVE_SMOKE.md](LIVE_SMOKE.md).

2. **Reference reconstruction — early-game baseline implemented.** Archived
   public metadata/screenshots, separated confirmed/inferred settings, changed
   the default run to an uncoached 1024-square API harness with checkpoint
   access, medium reasoning and complete conversation retention. Separate
   public-subset scorer reproduces seven reported agency scores. Disabled-PvE
   runtime checks, a paid uncoached calibration and its evidence audit pass;
   all 23 tests pass. See [REFERENCE_BASELINE.md](REFERENCE_BASELINE.md).

3. **Baseline comparison gate — next.** Freeze the common fixture, prompt,
   tools, context and resource policy before a matched multi-model suite.
   Exercise longer sessions without silent context changes. Preserve every
   attempted run, including call/cost stops. Resolve or clearly scope the
   inferred PvE/boss policy and advanced detector semantics. Exact upstream
   world/prompt/full scorer remain unavailable, so equivalence is not claimed.

4. **Improve the harness after the baseline.** Validate a distinct combat-enabled
   profile, stronger crafting/boss attribution, graceful saving, broader world
   coverage and worker isolation. Compare improvements against the frozen
   baseline rather than changing it during a model comparison.

5. **Full-game coverage.** Extend through mechanical bosses, Plantera/Golem,
   optional bosses, Cultist/pillars and Moon Lord. Validate each detector using
   real controlled trajectories. Keep campaign and isolated-task results
   distinct; add repeated matched worlds and uncertainty estimates.

6. **Research extensions.** Evaluate skill controllers, native coding-agent
   harnesses, correct full-simulation stepping and private test fixtures as
   separately named tracks. Publish only after validation and an explicit
   publication instruction. Autonomous full completion remains an empirical
   outcome, not a prerequisite for useful partial-progress measurements.
