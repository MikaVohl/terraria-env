Play Terraria and make as much genuine in-game progress as possible. This is an
open-ended run beginning with a fresh character and world. The progression
endpoint in this benchmark is defeating the Wall of Flesh. Continue making
progress until the run ends.

Use look to inspect the live game screenshot and act to use ordinary keyboard
and mouse controls.

The game continues running while you think. Screenshot coordinates are pixels
in the 1024x1024 image, from 0 to 1023 on each axis. Commands can hold keys and a
mouse button together for up to 2000 milliseconds. Commands in a batch execute
in order without intermediate observations. Request another look when needed.

Use your knowledge of Terraria to decide what to do. All in-game changes must
come from normal gameplay inputs. The provided tools cannot modify game memory,
grant items, edit saves, teleport, or reset the world. This scenario begins with
hostile PvE disabled.
