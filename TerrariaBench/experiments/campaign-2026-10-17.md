User authorization: broad experiments; Omarchy dedicated; session OpenRouter cap $3.
Prior recorded session spend: $0.086400375. New campaign cap: $2.90, including

## Questions

1. Does freezing the entire single-player process during inference remove game
   clock advance without a catch-up burst on resume?
2. Does screenshot/act orchestration matter (agent-requested look/act tools vs
   automatic observation after each structured action response)?
3. Do goal specificity and a short control/recipe guide change crafting outcomes?
4. Does structured inventory access expose a visual/UI bottleneck?
5. Do history compression, longer holds and simple motor macros help or hurt?
6. Are effects stable across model families and repeated attempts?

## Screening

Small one-factor contrasts against a frozen visual, real-time, normal-PvE,
open-ended baseline; same fresh save and 1024-square settings. Model IDs and
prices checked live. Initial models: Gemini 3.8 Flash; Claude Haiku 5.5;
DeepSeek V4.1 Flash 1017 where route availability permits. Reasoning medium
where supported, low for DeepSeek; this is reported, not claimed equivalent.

Variants: tool loop baseline; process-paused inference; PvE disabled; checkpoint
access; explicit wood/workbench task; task plus control/recipe guide; privileged
inventory tool; automatic-observation JSON loop; JSON loop with bounded
model-authored memory; long input holds; explicit open-loop motor macro.
The JSON-vs-tools contrast includes automatic observation scheduling, and does
not isolate only output grammar. History ablation compares two JSON loops.

Nominal screening limits: 16 API decisions, 300 wall seconds, 120 simulation
seconds for paused variants, per-attempt dollar reservation. Record actual
calls/actions/observations/game updates: equal call counts are not equal control
opportunity. Natural early-game mob exposure is measured, not guaranteed.

Adaptive follow-up: repeat informative contrasts; longer runs on promising
variants; derive explicitly inherited crafting fixtures only from valid paid
trajectories or separately labeled evaluator setup. Preserve a selection log.
Boss/late-game fixtures and native coding-agent frameworks are separate future
scope unless time/budget allow validated setup.

## Diagnostics

Distinct semantic progress families and raw checkpoint vector, resource maxima,
new crafted-station possession, deaths/damage, game updates, inference latency,
input duration, invalid outputs, observation age, context size, cost and stop
reason. Inspect trajectories; do not infer a failure cause from score alone.
All results exploratory/unofficial. Existing reference artifacts remain frozen.
