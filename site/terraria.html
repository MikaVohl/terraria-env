Official Terraria track

The same benchmark contract, played in the real game: Terraria 1.4.4 through tModLoader, scored from a checkpoint log written by a mod. It answers the question Terraria-Lite cannot: does an agent that does well in the simulator also make progress in Terraria itself, and at what cost?

No agent has been scored on this track yet. Every leaderboard row, chart mark and heatmap cell on this page is sample data that shows the layout the results will use. The contract below is a draft. The speed measurements in the speed section are real (experiments/tml-speed-20261107).

How fast is real Terraria?

We measured a headless tModLoader 1.4.4 dedicated server stepping Main.Update in a tight loop on an Intel i7-9700 (Linux), with a scripted player that walks, jumps and mines with a copper pickaxe. Each run is 30 s of steady state after a 5 s warm-up, repeated three times. One agent action is 4 game ticks.

What the measurement leaves out

Running a full client-side player on the server failed: sky, filters and player saving are not initialised on a dedicated server and threw exceptions. Combat, item pickup and cursor tool use need a headless client host, which has not been built. Episode resets would also need an in-memory world snapshot, since generating a small world takes 16 s. All of this makes the numbers above upper bounds on speed.

Source: experiments/tml-speed-20261107/README.md (method, raw JSONL and summary script in the same directory).
